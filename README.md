# 💰 Etsy Fee & Net Profit Calculator (Open Source Widget)

An accurate, responsive, zero-dependency Etsy fee and net profit calculator widget for e-commerce sellers, vintage collectors, and handmade digital crafters.

## 🛠️ Features
- **Listing Fee**: Calculates the standard $0.20 flat listing fee.
- **Transaction Fee**: 6.5% of total order value (including shipping charged to customer).
- **Payment Processing Fee**: 3% + $0.25 (standard US rate, configurable).
- **Optional Etsy Offsite Ads**: Toggle 12% or 15% tier for offsite advertising attribution.
- **Profit Margin & ROI Calculation**: Real-time breakdown of COGS, shipping cost, fees, and take-home net profit.
